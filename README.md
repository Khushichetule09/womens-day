# Happy Women's Day Landing Page

A beautifully designed, modern, and sensitive landing page to celebrate Women's Day. This project is built prioritizing aesthetics, showcasing a clean user interface, vibrant color theme, and responsive design.

## Features

- **Modern UI/UX**: Crafted with attention to detail, utilizing smooth transitions and a premium aesthetic.
- **Responsive Layout**: Ensures seamless viewing across all devices (mobile, tablet, and desktop).
- **Vibrant Typography & Colors**: A harmonious color palette tailored to fit the theme perfectly.
- **Optimized Assets**: Uses refined, modern iconography and lightweight assets for faster load times.

## Technologies Used

- **React**: Frontend library for building the user interface.
- **Vite**: Next-generation frontend tooling for rapid development.
- **Tailwind CSS**: Utility-first CSS framework for efficient and maintainable styling.
- **TypeScript**: Typed superset of JavaScript for enhanced code reliability.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have the following installed on your local machine:
- Node.js (v16.0 or higher recommended)
- npm or yarn or pnpm
